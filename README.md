# deceivableAI
Decision support tool - demo

Deceivable AI act as a digital twin for a fallible human observer. At its core, it's a rational decision-maker but extensions represent cognitive vulnerabilities such as confirmation bias, habituation, causal attribution error... Exposed to stimuli, the decision-maker interprets events as if it were human but because it is not human, it can tell you which extensions – and so which biases - have been triggered to arrive at any decision it makes. Where its human-like decision differs from its core rational decision, it can warn that exploitation or deception - or even a simple error of judgement - may be taking place and point its human operator to the cause.

Ablation interface lets users toggle individual biases on and off to observe how recommendations change, surfacing unconscious, reflexive responses to encourage critical thinking.
